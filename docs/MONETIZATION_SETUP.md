# Monetización

Ads y analytics salen apagados. Para activar ads: `PUBLIC_ENABLE_ADS=true`, client y slots reales, y CMP si aplica. `ADS_TXT_LINE` exacta del publisher; no commitear un pub inventado.

Afiliados: URL en datos, `rel="sponsored noopener"`, texto “Ver en Mercado Libre”. Sin URL, la guía se publica igual.

Consent: punto de configuración `PUBLIC_CONSENT_PROVIDER`. No hay banner casero haciéndose pasar por CMP.
